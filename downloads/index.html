A QUICK START

From click to
home screen.

Installing an APK is simple. Here's how.

View the project guide
  1. 01

    Pick an app. Download it.

    Tap Download APK on your Android phone. The file comes directly from this repository's GitHub release.

  2. 02

    Allow your browser to install.

    Open the downloaded file. If Android asks, allow “Install unknown apps” for your browser or file manager.

  3. 03

    Install, open, make it yours.

    Review the app's permissions and tap Install. You can turn off install permission again afterwards.

These are repository-signed developer builds, not Google Play releases. Only install apps you trust. Android may show a security prompt; keep Play Protect enabled. Updates need a compatible signing key.
